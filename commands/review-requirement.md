# SPECTRUM — Revue d'exigence

Analyse l'entrée fournie comme une revue ciblée des exigences.

Charge les éléments SPECTRUM nécessaires, notamment les compétences de qualité d'exigence, de contexte, de formulation, de relations et de traçabilité.

Retourne en français :
- résumé ;
- dimensions concernées ;
- constats avec preuves ;
- ambiguïtés, lacunes et contradictions ;
- impact sur l'implémentation ;
- questions ouvertes ;
- recommandation d'action suivante.

Ne décide pas d'un score. N'invente aucune exigence. Ne modifie aucun code, fichier, dépôt ou système externe sans autorisation explicite.
