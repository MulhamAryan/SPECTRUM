# SPECTRUM — Analyse depuis Jira

Utilise les outils Jira disponibles dans l'environnement lorsque la connexion est configurée.

Étapes :
1. Lire le ticket demandé.
2. Lire les commentaires et éléments liés accessibles lorsque nécessaires.
3. Préserver l'identité, les versions et les références Jira.
4. Fournir les informations à l'analyse SPECTRUM.
5. Produire le rapport utilisateur en français avec le format SPECTRUM.

Si aucun outil Jira n'est disponible, demander uniquement les éléments nécessaires sous forme de texte ou d'export fourni par l'utilisateur ; ne pas prétendre avoir consulté Jira.

Sécurité : lecture seule. Ne crée, ne commente, ne transitionne et ne modifie aucun ticket ou champ Jira sans autorisation explicite couvrant précisément l'opération et la cible.
