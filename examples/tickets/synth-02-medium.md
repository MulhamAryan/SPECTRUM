# PROJ-142 — Notifications de retard de paiement

Quand une facture est en retard, il faut envoyer une notification au client pour le relancer. Les clients se plaignent de ne pas être prévenus.

On veut pouvoir configurer le délai avant relance et le nombre de relances.

Le texte doit être professionnel et mentionner le montant dû.

Prévoir que le comptable puisse désactiver les relances pour un client donné.
