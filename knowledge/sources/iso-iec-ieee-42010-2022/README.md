# ISO/IEC/IEEE 42010:2022

This directory records how SPECTRUM uses ISO/IEC/IEEE 42010:2022 as an architecture-description reference for `/spectrum:document-feature`.

## Status

- Source: ISO/IEC/IEEE 42010:2022, *Software, systems and enterprise — Architecture description*.
- Role in SPECTRUM: conceptual reference informing the `architecture-description` and `architecture-reconstruction` skills.
- Evidence basis: **weaker than the 29148 precedent.** A direct fetch of the official ISO catalogue page (`iso.org/standard/74393.html`) returned HTTP 403 in this session. The scope statement in `knowledge.yaml` was corroborated from public search-result snippets quoting the same text across independent listings (ISO's own indexed summary, IEEE SA, ANSI/ITeh), not from direct OBP table-of-contents browsing.

## Important boundary

- The standard is the normative source.
- SPECTRUM does not reproduce its copyrighted text.
- Section/clause-level structure (unlike 29148's fully-browsed OBP TOC) is **not verified** in this session. Only the public scope/abstract statement is recorded as confirmed.
- The widely-known 42010 conceptual family (stakeholder, concern, view, viewpoint, architecture rationale/decision) predates and survives across editions in public secondary literature, but is recorded here as `UNVERIFIED` because this session could not fetch the 2022 edition's own clause text. It is listed in `knowledge.yaml` for future completion, never used as a rule basis.

## What SPECTRUM derives today

Only the confirmed public scope statement: an Architecture Description (AD) structures architecture for software/systems/enterprises/product lines/etc., distinguishes the entity's architecture from the AD expressing it, and defines conformance for AD/ADF/ADL/viewpoint/model kind. The standard explicitly does not prescribe process, method, notation, or format — SPECTRUM's `architecture-description` skill and the `ArchitectureElement`/`ArchitectureView`/`Concern` canonical entities are SPECTRUM implementation choices informed by, not dictated by, this scope.
